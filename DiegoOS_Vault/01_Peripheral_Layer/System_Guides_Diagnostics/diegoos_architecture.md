# DiegoOS Vault Architecture Manual

This document establishes the binding structural layers and directional file-routing constraints for the DiegoOS vault system. The system layout isolates active operational pipelines from raw inputs and human-authored conceptual frameworks.

## 1. System Directory Configuration

The vault is divided into three distinct, non-overlapping architectural layers:

### 📂 01_Peripheral_Layer/
* **Operational Role:** Ingestion landing pads, system logs, system guides, and temporary workspace files.
* **Core Sub-directories:**
  * `A_Daily_Logs/`: Automated catchall directory for incoming daily scratchpads and raw checklist inputs.
  * `System_Guides/`: Technical manuals and prompt constraint rules enforcing system operational standards.
* **Enforced Controls:** Retains automated system instrumentation logs (`System_Diagnostics.md`) to measure background script execution telemetry.

### 📂 02_Inner_Layer/
* **Operational Role:** The strictly human-authored conceptual core. Machine-generated prose is entirely barred from settling here.
* **Core Sub-directories:**
  * `Conceptual_Notes/`: Theoretical drafts, notes, and direct thought logs generated by the user.
  * `Literature/`: Fragmented reference extractions, primary source logs, and literature citation keys used for building academic arguments.
* **Enforced Controls:** Automated background triage routines systematically strip conversational AI greetings and analytical commentary when processing raw text entries destined for this layer.

### 📂 03_Outer_Layer/
* **Operational Role:** The constraint-enforced execution engine managing external project milestones, target applications, and production-ready text layers.
* **Core Sub-directories:**
  * `Active_Missions/`: Active job application files, research proposals, grant drafts, and current project pipelines formatted as standardized tracking cards.
  * `Dashboards/`: High-visibility master index ledgers (`Active_Dashboard.md`) displaying urgent actions and time-critical countdown tracks.
* **Enforced Controls:** Frontmatter-driven logic gates dynamically manage file modification privileges across this layer based on upcoming deadlines.

### 📂 _Cold_Storage/
* **Operational Role:** The quarantined staging sector and structural historical repository.
* **Enforced Controls:** Holds unstructured historical files, legacy application logs, and raw copy-pasted data pools awaiting script-driven migration loops. This folder is globally hidden from active vault search indexing and command panels.
